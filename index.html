Snake Madness Live

A personal, interactive livestream game for the YouTube channel @PoogooGames. Viewers type commands in the YouTube live chat, and the game turns them into actions in a Snake game.

What it is

Snake Madness Live is a Snake game that is shown on a YouTube livestream. During a livestream, viewers write one of a fixed list of commands in the live chat (for example /Bomb or /Freeze). Reading the chat by hand while streaming is not practical, so the application reads the live chat automatically and triggers the matching game action.

How it works with YouTube

  1. The channel owner signs in with their Google account using Google OAuth and grants one read-only permission (youtube.readonly).
  2. When the owner is live, the application uses the YouTube Data API v3 to find the active livestream and read its live chat messages.
  3. Only messages that contain one of 12 fixed commands are kept as pending commands. All other chat text is ignored.
  4. At an interval set by the owner, the game picks one pending command at random, shows the viewer’s display name and the command on screen, and runs the matching effect in the game.
  5. The updated game is visible to everyone in the livestream video.

The application only reads. It does not post, delete or moderate chat messages, and it does not change anything on the YouTube channel.

Where it runs

Snake Madness Live runs on the game owner’s own private computer, as a small local program that serves the game to the owner’s browser at a local address. It is not hosted as a public web application, it has no public sign-in and no user accounts, and it is not offered as a service to other people. This website is an information page only and does not run the game.
