Privacy Policy

Snake Madness Live · Last updated: November 14, 2026

1. About the application

Snake Madness Live (“the application”) is a personal, interactive livestream game for the YouTube channel @PoogooGames. During a livestream, viewers write commands in the YouTube live chat and the application converts them into actions in a Snake game. The application is used by its owner for the owner’s own livestreams. It runs locally on the owner’s computer and is not a public, hosted web application.

2. Use of YouTube and Google APIs

The application uses YouTube API Services (YouTube Data API v3), mainly to read the live chat of the owner’s livestream. It uses Google OAuth 2.0 to obtain authorization. By using YouTube features, the channel owner is bound by the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy.

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

3. Authorization (who signs in and what is requested)

  • Only the game owner / stream owner signs in with Google. Viewers never sign in to the application and give it no access to their accounts.
  • The application requests one read-only permission: https://www.googleapis.com/auth/youtube.readonly (“View your YouTube account”).
  • The application uses this access to: confirm that the signed-in account owns the channel @PoogooGames, find the owner’s active livestream, and read that livestream’s live chat messages.
  • The application does not post, delete or moderate chat messages and does not change the channel, videos or settings.

The viewer’s display name and the command are shown on screen when a command is picked, so they are visible in the livestream video. Display names are already public in YouTube live chat.

5. What we do not do

  • We do not collect viewers’ personal information beyond the command message and public display name described above, and we do not store it beyond temporary use.
  • We do not sell, rent, or share viewer data, and we do not use it for advertising or profiling.
  • We do not send data from the application to any other server or third party. Its only network communication is with Google and YouTube for sign-in and for reading the live chat, plus the local connection between the program and the owner’s browser.
  • We do not put any API key, client secret, OAuth token or other credential in this website or its HTML.

6. Local processing and security

The main processing happens on the game owner’s computer. The local program accepts connections only from the same computer and protects its local interface with a random token generated each time it starts. The owner is responsible for keeping the computer, the OAuth client file and the token file private.

7. Revoking access and deleting data

  • The owner can sign out inside the application, which deletes the saved token file.
  • The owner can also revoke the application’s access at any time in the Google Account permissions page: myaccount.google.com/permissions.
  • Closing the program clears all in-memory data. The owner can delete the application’s local folder and the browser’s saved site data to remove everything else.
  • A viewer who does not want a chat message used can simply not post a command, or delete their own message in YouTube. Viewers can contact us about privacy concerns using the contact below.

8. Children

The application is not directed at children and does not knowingly collect personal information from children. It only processes the public live chat messages of the channel’s livestream, as described above.

9. Changes to this policy

If the application’s use of data changes, this policy will be updated and the “Last updated” date will change.
