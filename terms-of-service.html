Snake Madness Live (“the application”) is a personal, interactive livestream game used by the owner of the @PoogooGames YouTube channel (“the owner”). During the owner’s livestreams, viewers write commands in the YouTube live chat and the application turns them into actions in a Snake game.

By watching the livestream and writing in its live chat, or by using the application as its owner, you agree to these Terms. If you do not agree, please do not use the application or write commands in the chat.

4. What the application does with chat

  • The application reads YouTube live-chat messages of the owner’s livestream and recognizes only its fixed slash commands (/ChangeSnakeColor, /ChangeTheme, /SpawnApples, /FireRun, /SpawnGoldenApple, /Fart, /AppleRain, /RainbowMode, /Bomb, /Surprise, /Freeze, /Kill). All other chat text is ignored.
